# Gauri Web Solutions — Portfolio Starter

A responsive React + Vite portfolio website. It uses regular CSS (no Tailwind).

## Run on your laptop
1. Install Node.js (LTS) from https://nodejs.org/
2. Extract this ZIP.
3. Open the extracted `gauri-web-solutions` folder in VS Code.
4. Open Terminal in VS Code and run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local address printed by Vite (usually http://localhost:5173).
